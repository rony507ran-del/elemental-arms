# Elemental Arms — مود فابريك لـ Minecraft Java 1.21.11

ثلاثة أسلحة:

| السلاح | الاستخدام (كليك يمين) | التأثير |
|---|---|---|
| **Grappling Hook** (خطّاف التسلّق) | وجّه على أي بلوك لين 48 بلوك | يسحبك للبلوك بسرعة. كليك يمين مرة ثانية أو Shift أو تغيير السلاح = تفلّت. ما تاخذ ضرر سقوط بعد التفلّت (ثانيتين) |
| **Fire Gun** (مسدس النار) | طلقة فورية لين 48 بلوك | أي كائن حي تصيبه يحترق **لين يموت**: الماء ما يطفيه، ومقاومة النار ما توقفه، والكائنات المقاومة للنار (بليز، ويذر سكيليتون...) تتضرر بضرر سحري. يرجع يحترق حتى لو طلعت من الشنك أو سكّرت السيرفر |
| **Ice Gun** (مسدس الجليد) | طلقة فورية لين 48 بلوك | أي كائن حي تصيبه يتجمد **5 ثواني** ما يتحرك ولا يهاجم. اللاعبين ما يمشون ولا يقفزون. إذا انطلقت مرة ثانية يتجدد العدّاد |

## البناء

المتطلبات: Java 21 أو أحدث + إنترنت (لتحميل Gradle وFabric وMinecraft أول مرة).

```
cd elemental-arms
./gradlew build        (ويندوز: gradlew.bat build)
```

الملف الجاهز يطلع في `build/libs/elementalarms-1.0.0.jar` (لا تستخدم ملف `-sources`).

## التركيب

1. ثبّت أحدث Fabric Loader لإصدار 1.21.11 (من fabricmc.net/use)
2. حط **Fabric API** (نسخة 1.21.11) في مجلد `mods`
3. حط `elementalarms-1.0.0.jar` في نفس المجلد

المود يشتغل على السيرفر والكلاينت، ولو على سيرفر خلّه عليه وعلى اللاعبين.

## الوصفات (Crafting)

- Grappling Hook: 3 حديد + سلك تعثّر (tripwire hook) + خيط
- Fire Gun: 4 حديد + قداحة + عصا بليز
- Ice Gun: 4 حديد + جليد مضغوط + جليد أزرق

أو خذها من تاب القتال في الوضع الإبداعي، أو `/give @s elementalarms:fire_gun`.

## تعديلات سريعة (في الكود)

- سرعة الحرق/الضرر: `BurnManager.java` ← `DAMAGE` و `DAMAGE_INTERVAL_TICKS`
- مدة التجميد: `FreezeManager.java` ← `FREEZE_TICKS` (100 = 5 ثواني)
- سرعة السحب والمدى: `GrappleManager.java` ← `PULL_SPEED` و `RANGE`
- فترة الانتظار بين الطلقات: ثوابت `COOLDOWN_TICKS` داخل كل ملف سلاح
